## Intro
> 🔗 https://en.wikipedia.org/wiki/Chaff_algorithm

**Chaff** is an [algorithm](https://en.wikipedia.org/wiki/Algorithm "Algorithm") for solving instances of the [Boolean satisfiability problem](https://en.wikipedia.org/wiki/Boolean_satisfiability_problem "Boolean satisfiability problem") in programming. It was designed by researchers at [Princeton University](https://en.wikipedia.org/wiki/Princeton_University "Princeton University"). The algorithm is an instance of the [DPLL algorithm](https://en.wikipedia.org/wiki/DPLL_algorithm "DPLL algorithm") with a number of enhancements for efficient implementation.
